# Lupita, mi última herencia

Sitio web en un único archivo `index.html`.

## Publicación en GitHub Pages
1. Crea un repositorio público llamado `Lupita`.
2. Sube **solo `index.html`** a la raíz del repositorio (no subas el ZIP).
3. En Settings > Pages selecciona Deploy from a branch, main, /(root), Save.
4. Visita https://baambamm.github.io/Lupita/ después de unos minutos.

El HTML incluye estilos e imágenes incrustados. Los enlaces de compra deben sustituirse por los oficiales antes de entregar al cliente.
